## О проекте

React-приложение для сокращения длинных URL: ввод ссылки, генерация короткого адреса через TinyURL API, QR-код и история сокращений. Своего бэкенда нет — сокращение делает TinyURL API, история сохраняется в `localStorage` браузера.

---

## Возможности

- Сокращение URL через TinyURL API (нужен собственный API-токен)
- Валидация ссылки перед отправкой запроса
- QR-код для каждой сокращённой ссылки (`qrcode.react`) — удобно сканировать с телефона
- Копирование в буфер обмена одним кликом с визуальным подтверждением «Скопировано»
- История сокращений: последние 50 ссылок, относительное время («5 мин. назад»), удаление отдельной записи и очистка всей истории
- Кибер-панк оформление: анимированная сетка на фоне, неоновая палитра, моноширинные шрифты (Space Mono, JetBrains Mono)
- Адаптивная вёрстка под планшет и телефон

## Быстрый старт

Нужен [Node.js](https://nodejs.org/) версии 18 или новее.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Topchikdan/CutURL.git
cd CutURL

# 2. Установите зависимости
npm install

# 3. Запустите в режиме разработки
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

## Структура проекта

```
src/
├── components/
│   ├── UrlForm.jsx          # форма ввода ссылки и кнопка «Сократить»
│   ├── ResultCard.jsx       # карточка результата: короткая ссылка + QR-код
│   ├── ResultCard.css
│   ├── HistoryList.jsx      # список истории сокращений
│   └── HistoryList.css
├── utils/
│   └── urlUtils.js          # валидация URL, форматирование даты, копирование в буфер
├── App.jsx                  # состояние приложения, запрос к TinyURL API, работа с localStorage
├── App.css                  # глобальные стили и стили формы
└── main.jsx                 # точка входа
```

---

## Хранение данных

История сокращённых ссылок хранится в `localStorage` браузера под ключом `cuturl_history` и ограничена 50 последними записями — никакая база данных не используется.
