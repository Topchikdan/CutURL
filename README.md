# CutURL — сервис для сокращения ссылок

React-приложение для сокращения длинных URL: ввод ссылки, генерация короткого
адреса через TinyURL API, QR-код для неё и история сокращений. Своего бэкенда
нет — сокращение делает TinyURL API, а история сохраняется в localStorage браузера.

## Возможности

- **Сокращение URL** — через TinyURL API (нужен собственный API-токен).
- **Валидация ссылки** перед отправкой запроса.
- **QR-код** для каждой сокращённой ссылки (`qrcode.react`) — удобно сканировать с телефона.
- **Копирование в буфер обмена** одним кликом, с визуальным подтверждением «Скопировано».
- **История сокращений** — последние 50 ссылок, относительное время («5 мин. назад»), удаление отдельной записи и очистка всей истории.
- **Кибер-панк оформление** — анимированная сетка на фоне, неоновая палитра, моноширинные шрифты (Space Mono, JetBrains Mono).
- **Адаптивная вёрстка** под планшет и телефон.

## Запуск

Нужен [Node.js](https://nodejs.org/) версии 18 или новее.

```bash
# Установить зависимости
npm install

# Запустить дев-сервер
npm run dev

# Собрать production-сборку
npm run build

# Посмотреть production-сборку локально
npm run preview
```

После `npm run dev` откройте адрес из терминала (обычно `http://localhost:5173`).

## Настройка API

Сокращение ссылок работает через [TinyURL API](https://tinyurl.com/app). Чтобы получить токен:

1. Зарегистрируйтесь на tinyurl.com и зайдите в настройки аккаунта.
2. Создайте API-токен.
3. В корне проекта создайте файл `.env` и добавьте:

```
VITE_TINYURL_API_TOKEN=ваш_токен
```

Без токена форма сокращения вернёт ошибку «API токен не настроен».

## Хранение данных

История сокращённых ссылок хранится в `localStorage` браузера под ключом `cuturl_history`
и ограничена 50 последними записями — никакая база данных не используется.
